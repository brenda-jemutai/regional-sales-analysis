# Regional Sales Performance Analysis

An end-to-end data analysis project exploring regional sales performance using SQL, Excel, and Power BI.

## 📊 Project Overview
This project analyzes a 150-record sales dataset (Date, Region, Product, Salesperson, Amount) to answer:
- Which regions and salespeople drive the most revenue?
- How does performance break down by product?
- How do sales trend over time?

## 🛠️ Tools & Skills
- **SQL:** CTEs, window functions (RANK), CASE WHEN, JOINs
- **Excel:** XLOOKUP, INDEX/MATCH, SUMIF/COUNTIF, PivotTables, PivotCharts
- **Power BI:** DAX measures, data modeling, slicers, interactive dashboard

## 📁 Repository Structure
- `sql/` — SQL queries used for the analysis
- `excel/` — Excel workbook with PivotTables and formulas
- `powerbi/` — Power BI dashboard file and screenshots

## 🔍 Key Insights
- Nairobi leads in total sales among the four regions, with Nakuru and Mombasa close behind.
- Kisumu records the lowest total sales, suggesting an opportunity for targeted sales support or promotions there.
- The dashboard includes a Sales YTD (Year-to-Date) measure to track cumulative performance over time.
